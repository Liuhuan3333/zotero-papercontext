# 隐私、保存与费用

## 发送什么

模型翻译请求可能包含：选中文字、受限的附近正文、论文标题及相关术语。接收方是你选中的模型服务提供商。插件不会为了提高缓存命中率而发送整篇论文、无关填充文本或预热请求。

项目没有自建翻译中转服务器，不提供统一账号或共享 API Key。

## 本机保存什么

- API Key：使用 Zotero 登录凭据管理器，按提供商隔离，设置页不回显。
- 模型、字号、显示模式、两种显示宽度、验证记录：使用 Zotero 偏好。验证记录包含配置修订与时间，不保存密钥或密钥哈希。
- 论文术语和译文缓存：存放在 Zotero profile 中的 `contextleaf/state.json`。此路径是插件内部兼容标识，不是文献附件目录。

这些数据不由插件自动同步，不写入原始 PDF。可以在退出 Zotero 后备份独立数据文件；不要编辑正在使用的文件，也不要将其作为公开问题附件上传。

“清除译文缓存”保留论文术语；“删除此服务密钥”只影响当前服务。卸载插件会保留数据以便重装。需要彻底移除时，先在设置页依次删除各服务的 Key，退出 Zotero 后删除独立的 `contextleaf` 目录，不要删除整个 profile 或文献库。

## 上下文和缓存限额

| 情况 | 默认额外上下文 |
| --- | --- |
| 短词/缩写，选区最多80字符且不超过8个空白分词 | 最多420字符，优先所在句 |
| 短句 | 最多900字符，优先附近段落 |
| 至少500字符的长选区 | 不额外重复附近正文 |
| 手动“更多上下文重译” | 最多2400字符 |

标题另限160字符；相关术语最多12条、总计700字符；单次选区上限3500字符。以上是字符限额，不是精确 Token 数。

短词翻译会尽量将所在句作为稳定输入前缀，选区可能在句子和选区字段中各出现一次。手动增强由用户主动触发，不自动追加第二次请求。

本地缓存最多100条，按论文、语境、术语修订、提供商、接口和模型区分；修改术语后不继续复用该论文的旧缓存。

## 费用如何理解

- 本地术语命中或译文缓存命中：不调用 API。
- 模型请求：按服务商规则收费。浮窗使用服务返回的真实用量，未返回时明确标注。
- 服务端输入缓存：由服务商自动管理，命中不等于免费，也不保证每次相同前缀都命中。
- 查看设置、切换提供商、调字号：不发送模型请求。
- 取消请求：只停止本地等待或中止未完成传输；平台已经接收的请求仍可能计费。

模型仍可能误译。请自行评估是否适合向所选服务发送未公开或受限制的论文内容。
