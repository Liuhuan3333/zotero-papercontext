# Teal bookmark visual design

Approved direction: a teal research reading companion with warm apricot accents. Compared with the blue-purple technology direction and cream journal direction, teal keeps text calm while giving the product a clear identity.

Apply to the plugin icon, settings, selection popup and fixed sidebar. Use a book/bookmark symbol, the line “读懂词，也读懂语境。”, grouped font controls, small labeled action icons, a distinct source-text area, local-result badges, a three-dot loading indicator and brief saved-term feedback. Follow Zotero light/dark appearance and reduced-motion settings. Status text must retain the configured/previously-verified distinction.

No new API calls, no model or context changes, no additional setup and no change to display-mode, resizing, dismiss or persistence behavior. Keep translation typography at the remembered size. The user's approval authorizes applying this design, updating the existing installation and publishing the release.
