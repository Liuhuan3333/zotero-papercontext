# 新手入门：从安装到第一次划词翻译

你不需要会编程，也不需要安装 Python、Node.js 或搭建服务器。通常只需要已有的 Zotero 10 和一个模型平台的 API Key。

## 1. API Key 是什么？

API Key 是模型平台发给你的调用凭据，可以理解为允许插件使用该平台模型的钥匙。它不是 Zotero 密码，也不等于聊天网站的登录密码。

如果还没有 Key，打开插件设置页，选中服务，再点击“查看当前提供商的官方接入说明”，按平台指引创建自己的 Key。不要把 Key 发给他人或上传到 GitHub。模型请求可能收费，账号需要有相应模型的调用权限。

## 2. 安装研译

1. 下载项目提供的 `.xpi` 安装包，不需要下载整个源码。
2. 打开 Zotero → 工具 → 插件。
3. 点击齿轮 → 从文件安装插件，选择刚下载的 XPI。
4. 打开 Zotero 设置 → 研译。

如果浏览器显示的是 GitHub 文件页，点击下载原始文件。不要把网页另存为 `.xpi`。

## 3. 填入 Key

选择服务 → 粘贴该平台的 Key → 保存密钥 → 检查连接。接口地址和默认模型已经预填，通常不需要展开高级设置。

“已配置”说明 Key 已保存；检查成功后，会显示上次验证成功及时间。保存后输入框变空是正常的，插件不会回显你的 Key。

如果平台账号未开通模型，或你使用的是业务空间专用 Key，需要按状态提示检查权限，或在高级设置补充业务空间/接入点信息。不能通过填写别家平台的 Key 解决当前平台的权限问题。

## 4. 开始阅读

打开带可选文字的 PDF，用鼠标选择一个词或一句话。松开后稍等片刻，译文会出现在选区旁。

- 字小：点击浮窗 A＋；字大：点击 A−。选择会被记住。
- 译法不符合上下文：点击“更多上下文重译”。
- 专业术语译错：点击“纠正术语”，保存到当前论文。
- 暂时不想翻译：在高级设置暂停自动划词翻译。

## 常见疑问

**填了 Key，为什么仍然显示尚未验证？**
保存 Key 不会自动发送请求。主动检查连接或完成一次真实模型翻译后，状态才会更新。

**是否免费？**
插件代码采用 MIT 开源许可；模型调用是否收费取决于你的服务商和账号。本地术语或译文缓存命中不调用 API。

**重复选择为什么很快？**
可能命中了本地缓存。浮窗会明确显示“本次未调用 API”。

**扫描件为什么不能划词？**
扫描件可能只有图片，需要先自行 OCR。当前插件不提供 OCR。

**更新会丢失 Key 和术语吗？**
直接覆盖安装兼容的新版本即可，不要先删除数据。本项目保留了既有配置和术语的升级兼容标识。
